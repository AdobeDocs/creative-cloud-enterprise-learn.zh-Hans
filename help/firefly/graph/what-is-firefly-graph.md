# &#x200B;1. 什么是[!DNL Firefly Graph]？

大多数生成式AI工具都会从一个提示中为您提供一个输出。 如果短片有所改变，您便可以手工重建整个文件，而除了最终文件，再无其他事情可做。

萤火虫图的工作方式不同。 您构建的&#x200B;**图形**&#x200B;不是单个提示，而是一个可视化的分步工作流程，其中每个输入、转换和输出都捕获在一起。 更改一个步骤并重新运行 — 您不会重建整个链。 每一步都是您的团队可以完整地检查、调整和移交的可见节点。

![视觉图形屏幕截图](../assets/graph.png){align="center"}

简而言之，图形并不会替换您的创意流程，而是将该流程转变为您可以看到、重复使用和缩放的流程。

## 您的步骤，设为可见

思考您今天已经运行的工作流程：从简单开始，收集您的输入，进行变体、优化、导出。 图形不会更改这些步骤 — 它使每个步骤可见并可重复使用：

| 今天的工作流程 | 图形使哪些内容可见 |
|---|---|
| 从简要内容开始 | 摘要成为图形输入 |
| 收集输入 | 输入直接连接到节点 |
| 制作变体 | 变化以并行方式运行 |
| 优化 | 优化一个节点，而无需接触其余节点 |
| 导出 | 直接从图形导出 |

这就是转变：同样的工作，但沿途中的每个决定现在都可以看到、修改和重复使用 — 而不是必须从头开始重做的黑框。
