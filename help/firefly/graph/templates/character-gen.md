# 一致的字符生成

了解如何载入角色的一个参考图像，然后为每个新拍摄交换场景或姿势提示。 [打开一致字符生成模板](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:6ab4c3c7-ead2-5fa5-9441-75b7a362ce11)。

[!BADGE 行业示例]{type=Informative tooltip="行业示例"}

* **旅行** — 在多视频目标系列和社交内容中保持反复出现的指南或吉祥物角色一致，而无需为每个场景重新简报插画家。
* **零售** — 在几十个季节性产品照片和社交帖子中保留一个品牌化轮辐角色。
* **教育** — 使课程中每个课程视频的动画讲师角色保持一致。

>[!TIP]
>
>**开始之前** — 为获得最佳效果，请根据您自己的品牌、产品和工作流程自定义此模板。 在使用任何输出之前，交换参考图像、提示和副本。
