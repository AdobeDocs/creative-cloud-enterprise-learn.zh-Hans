# 可选颜色校正

了解如何遮盖需要校正的特定区域，并仅在该节点上设置目标颜色。 图像的其余部分原封不动地通过图形。 [打开可选颜色校正模板](https://firefly.adobe.com/graph/edit/id/urn:aaid:sc:US:92c1c93e-4a12-5c99-a2d7-a06ad1662125)。

[!BADGE 行业示例]{type=Informative tooltip="行业示例"}

* **通信与电信** — 整批零售商店摄影中正确的品牌颜色，使每个位置都匹配品牌的签名颜色，而无需完全考虑。
* **零售** — 在不一致的光照下拍摄的照片集中标准化产品颜色。
* **财务** — 在发布之前，整批营销摄影作品中的游离品牌颜色进行更正。

>[!TIP]
>
>**开始之前** — 为获得最佳效果，请根据您自己的品牌、产品和工作流程自定义此模板。 在使用任何输出之前，交换参考图像、提示和副本。
