# 将矢量图移动到InDesign布局中并将其打包以交接

打印机就绪文件意味着要跟踪链接、出血、字体和溢流文本。 了解如何在InDesign中询问AI Assistant来检查打印版面是否有出血、溢流文本和缺失字体或链接，并获得修复。 然后在“Preflight”（印前检查）中确认并打包移交所需的所有内容。
