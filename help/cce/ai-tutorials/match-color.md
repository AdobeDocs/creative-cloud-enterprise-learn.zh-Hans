# 跨镜头匹配颜色 — 无需色轮

了解如何使用Premiere中的颜色模式，使照片以不同的方式照亮，看起来像是属于同一编辑内容。 了解如何平衡一个镜头，将该等级复制到类似的剪辑中，并微调特定颜色，例如泳池的蓝色，以便您的编辑从剪切到剪切感觉一致。
