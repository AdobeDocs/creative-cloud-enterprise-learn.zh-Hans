# 构建预设，使整个拍摄的颜色保持一致

了解如何在不逐张编辑每个图像的情况下，使整个照片看起来保持一致。 在本教程中，了解如何在Lightroom中构建颜色预设，然后使用Firefly中的批量操作对一批图像应用该颜色分级。 您的文件将恢复为与原始文件相同的格式和像素大小。 观看教程，并在下次拍摄时试用。
